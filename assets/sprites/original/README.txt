Папка ресурсов для игры EarthShaker

Структура папок:
- sprites/ - спрайты и изображения
- sounds/ - звуковые эффекты (.wav, .ogg)
- music/ - фоновая музыка (.ogg, .mp3)

Для добавления спрайтов:
1. Поместите файл art.png в папку sprites/
2. Или добавьте отдельные файлы спрайтов

Поддерживаемые форматы:
- Изображения: PNG, JPG, BMP
- Звуки: WAV, OGG
- Музыка: OGG, MP3
